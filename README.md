# QuickNotes App

## Description
QuickNotes is a responsive note-taking web application built from scratch. It allows users to create, categorize, search, and delete notes, with all data saved locally in the browser so it survives page refreshes.

## Features
* **Add Notes:** Create notes assigned to specific categories (Personal, Work, Study).
* **Input Validation:** Prevents empty submissions and limits notes to a maximum of 200 characters.
* **Search Functionality:** Filter existing notes in real-time using the search bar.
* **Data Persistence:** Notes are automatically saved to `localStorage`.
* **Delete Notes:** Remove individual notes from the list and storage.

## How to Run Locally
1. Download or clone this repository to your local machine.
2. Navigate into the `quicknotes-app` folder.
3. Double-click the `index.html` file to open the application in your default web browser.
